> **Q3 (structural · ERFT-G):** Does exploiting nest algebra via generalized $C(c)$ add stability — and does $\Phi$ benefit disproportionately under the same operator?

## Abstract

Recent RSI methodology stresses matched persistence-on/off runs and frozen evaluators. ERFT imports that discipline into Infinite Octaves:

1. Fix recursion $F$, depth $N$, evaluator, and datasets.  
2. **ERFT-C:** vary **only** the scalar $c$ in an invariant transform graph $D_{n+1}=F(D_n,c)$.  
3. **ERFT-G:** apply the same generalized closure $C(c)$ to every arm (no Φ-only affordance).  
4. Measure **NRMSE** primary RFD, stepwise drift, path length, recovery ratio, and paired $\Delta_i=\mathrm{RFD}_{\mathrm{baseline},i}-\mathrm{RFD}_{\Phi,i}$.  
5. Compare five arms + blind ladder + continuous sweep + depth optima $c^*_n$.

**V5 ships executable** under `research/synthobs-egs-recursive-fidelity-test/` with protocol id `ERFT-V5-2026-09-27`. Suite pass means the protocol ran cleanly — **not** that $\Phi$ minimized drift. V1 = coarsening-bias receipt; V2 = fair severity but non-RSI geometry; V3 = nest partitions with $c$-geometry confound; V4 = exploratory combined architecture (retired as primary causal claim).

## 1. Question (falsifiable)

Let $D_0$ be original data. Recursion produces $D_{n+1} = F(D_n, c)$.

Primary curves (V5):

$$
\mathrm{RFD}_n = \mathrm{NRMSE}(D_n, D_0) = \frac{\mathrm{RMSE}(D_n, D_0)}{\sigma(D_0)}
$$

plus stepwise $\mathrm{Dist}(D_{n+1},D_n)$, cumulative path length $\sum \mathrm{Dist}(D_{i+1},D_i)$, and recovery ratio $\mathrm{Dist}(D_n,D_0)/\sum\mathrm{Dist}$.

Interest is **cumulative** behavior (depth $N$) and **paired cell structure** — not only a mean over heterogeneous aggregates.

## 3. Mechanisms (pre-registered · V5 dual-layer locks)

**The constant-only arm holds the recursive transformation graph invariant and changes only the scalar parameter $c$. Separate grammar-enhanced arms test whether constant-symmetric algebraic structure provides additional recursive-fidelity effects.**

| Layer | Rule |
|-------|------|
| **ERFT-C** | Identical algorithm for every arm. Nest weights = unit-normalized $(1/c,\,1/c^2)$. Lags / blocks / period are **generation-matched** (identical across arms). **No** special recursion, closure, or Φ-only re-entry. |
| **ERFT-G** | Same as ERFT-C plus generalized closure $C(c)$ available to **every** constant (symmetric). Asks whether nest algebra adds stability. |

| ID | Mechanism |
|----|-----------|
| A | Scaling — nest-weighted blend of two matched lags |
| B | Recursive weighting — prior generation at matched lags (+ $C(c)$ in ERFT-G) |
| C | Hierarchical resolution — dual matched blocks; nest-weighted recon |
| D | Recursive feedback — fixed gain; nest-weighted multi-scale target (+ $C(c)$ in ERFT-G) |
| E | Recursive compression — matched block budget; nest-weighted recon (+ $C(c)$ in ERFT-G) |

**E0c** locks unit-sum mix for all arms + constant-neutral geometry. **E0d** locks identical lags/blocks across named arms. **E0b** locks construction anti-bias.

## 5. Metrics

- **Primary:** NRMSE (scale-normalized RMSE)  
- **Secondary:** MAE; shape fidelity (Pearson); amplitude fidelity  
- **Drift geometry:** origin distance, stepwise drift, path length, recovery ratio  
- **Paired $\Delta_i$:** mean, median, std, fraction $\Delta>0$, Cohen's $d$, bootstrap 95% CI, sign-flip permutation $p$  
- **Blind ladder:** unlabeled constants including $\Phi$  
- **Sweep:** $c \in [1.0, 2.5]$ with train/hold (optimality falsifier — report prominently)  
- **Depth optima:** $c^*_n=\arg\min_c \mathrm{RFD}_n(c)$ for $n\in\{1,2,4,8,16,24\}$  
- **Engineering threshold:** 15% is an **engineering significance band**, not a statistically validated effect size

---

## 6. What counts as compelling (pre-registered)

A meaningful $\Phi$ advantage under **ERFT-C** requires lower paired drift across domains, surviving decoys, depths, held-out series, and multiple metrics — with $\Phi$ specified before confirmatory hold-out. **Absence of advantage falsifies the strong numerical claim for the locked fixture set.** Sweep minima away from $\Phi$ falsify the strong optimality claim. Development evidence (V1–V4) is distinguished from confirmatory V5 constant-neutral evidence.

### 7.2 ERFT-C · Five-arm matched (E1) — primary causal

**Primary endpoint:** named four-arm mean NRMSE under **constant-neutral** recursion (baseline · $\Phi$ · $\sqrt{2}$ · $e$).

| Arm | Mean final NRMSE (all E1 cells) |
|-----|--------------------------------|
| Baseline | **1.387** |
| **$\Phi$** | **1.426** |
| $\sqrt{2}$ | 1.414 |
| $e$ | 1.481 |

**Paired $\Delta_i=\mathrm{RFD}_{\mathrm{baseline},i}-\mathrm{RFD}_{\Phi,i}$** ($n=30$ matched cells): mean **−0.039** · median **+0.007** · fraction $\Delta>0$ **0.80** · Cohen's $d$ **−0.14** · bootstrap 95% CI **[−0.148, +0.030]** · sign-flip permutation $p$ **0.77**.

**Read carefully:** $\Phi$ is lower than baseline in **80% of matched cells**, yet the **mean** NRMSE slightly favors baseline because a minority of large opposite cells dominate the average — the aggregation trap the architecture audit warned about. The permutation test does **not** reject the null. Under ERFT-C, this fixture set does **not** establish a clean numerical causal advantage for $\Phi$.

### 7.3 ERFT-G · Generalized closure (E1g)

Grammar vs neutral mean-NRMSE deltas (`c_neutral − c_grammar`; positive would mean grammar lowered drift): baseline **−0.121** · $\Phi$ **−0.127** · $\sqrt{2}$ **−0.127** · $e$ **−0.114**. On these fixtures, symmetric $C(c)$ **increased** mean drift for every named arm; $\Phi$ did not benefit disproportionately.

### 7.9 ERFT-D · Dynamic Constant Regulation (exploratory extension)

**ERFT-D does not rewrite §7.1–7.7.** V5 remains the locked confirmatory baseline. ERFT-D asks a different question:

> Can recursive fidelity be improved by dynamically selecting among multiple constants ($c_n = G(\mathrm{state},n)$) rather than using one fixed $c$ throughout recursion?

| Sub-lane | What it tests |
|----------|----------------|
| **D0** | Fixed-constant controls ($1$, $\sqrt{2}$, $\Phi$, $e$) — static policy baseline |
| **D1** | Prescribed multi-constant sequences (alternating, cyclic, seeded random) |
| **D2** | State-dependent switching from observable drift state only (frozen evaluator; no future leakage) |
| **D3** | Adaptive one-step look-ahead on the candidate set (no hold-out peek; complexity accounted) |

**Separate hypotheses (do not conflate):** numerical $c=\Phi$ (ERFT-C) · generalized algebra $C(c)$ (ERFT-G) · dynamic mode selection $c_n=G(D_n)$ (ERFT-D).

**Φ peer discipline:** Φ remains one candidate among peers. Q1–Q6 separately ask whether Φ outperforms fixed peers, appears preferentially in dynamic policies, improves inclusion/exclusion, or is distinguishable from a nearby continuous proxy ($\approx 1.6$).

**Falsification allowed:** if the best fixed constant matches or beats dynamic policies, if random switching matches state-dependent rules, or if adaptive controllers collapse to one constant, the dynamic-regulation hypothesis is weakened — reported honestly.

**Live ERFT-D readout** (`ED_dynamic_constant_regulation`):

| Policy | Mean final NRMSE (lower better) |
|--------|----------------------------------|
| Best fixed constant (D0 aggregate) | **≈ 0.942** (named D0 means: **$e$ ≈ 0.943** · $\Phi$ ≈ 0.947 · $\sqrt{2}$ ≈ 0.948 · baseline ≈ 0.952) |
| Best prescribed sequence (**$e$ repeated** — not a mix) | ≈ 0.943 |
| State-dependent switch (D2) | ≈ 0.950 |
| Random-switch control | ≈ 0.950 |
| Adaptive look-ahead (D3) | ≈ 0.943 |
| Adaptive without $\Phi$ / near-$\Phi$ proxy | ≈ 0.943 (indistinguishable) |

- **Better combination?** **No** — no sequenced or dynamic policy beat best fixed.
- `dynamic_beats_best_fixed`: **false**
- `best_fixed_matches_or_beats_dynamic`: **true**
- `random_switching_equivalent`: **true**
- $\Phi$ preferential in dynamic policy: **false** (selection probability ≈ 1%)
- Inclusion/exclusion of $\Phi$: **no material change**
- **Hypothesis weakened** on these fixtures — exploratory negative, not a Φ rescue and not a homeostasis proof.

**Conceptual model:** recursive system → state → drift measurement → mode selection → transformation → new state, with mode set $\{1,\sqrt{2},\Phi,e,\ldots\}$.
