# Discussion {#sec:discussion}

## Implementation finding

The follow-up successfully exercised the larger-n receipt path without changing the frozen treatment or scoring definitions. This is an implementation result: statistics, figures, manuscript variables, and PDF composition can be regenerated from one committed receipt.

## Finding boundary

The deterministic control does not show that Lattice improves model accuracy or changes provider latency. Its structural token contrast only verifies that the report and manuscript can carry the intended estimands. The existing live receipts remain separate primary and exploratory evidence; they should not be pooled with this control.

## Implications

For future live work, the larger paired design is preferable to a single small run, but repeat count alone does not solve task leakage, model selection, or prompt confounding. The next live study should preregister task strata, validate model IDs, randomize task order, include a retrieval-only control, and retain prompt/completion token fields separately.

## Applicability

The implementation is applicable to repository experiments that need reproducible receipt-to-document injection and explicit evidence boundaries. Provider conclusions require live calls with valid credentials and a predeclared analysis. The deterministic fixture is not applicable as a production performance estimate.

## Limits of generalization

The live protocol still uses one small hand-authored task battery, heterogeneous task types, model-specific instruction following, and a compound coding gate. The follow-up adds no live model, no new provider, no independent task sample, and no achieved-power evidence. Optional-stopping and post-hoc escalation remain interpretive limitations for the live record.

## Honest conclusion

The mission's artifact and verification path is complete only for the deterministic control because live credentials were unavailable. The correct conclusion is therefore procedural and bounded: the larger-n analysis, injection, figures, and rendering pipeline are exercised and verifiable; provider claims require a later live run.
