# Manuscript syntax and figure registry

This project follows the ordered Markdown composition conventions of the template repository's `projects/templates/template_code_project/manuscript/`.

## Equations

Use Pandoc display math with labels:

```markdown
$$
\Delta = \bar{x}_A - \bar{x}_B
$$ {#eq:delta}
```

Use `[@eq:delta]` for references. Do not use raw `\ref` or `\eqref` macros in Markdown.

## Figures

Static figures live in `figures/` and are generated by `scripts/generate-manuscript-figures.mjs` from the primary JSON artifact.

| Label | File | Source |
|---|---|---|
| `{#fig:accuracy}` | `figures/primary_accuracy.svg` | primary JSON, `byTask` accuracy |
| `{#fig:tokens}` | `figures/primary_tokens.svg` | primary JSON, `byTask` tokens |
| `{#fig:paired}` | `figures/primary_paired.svg` | primary JSON, paired treatment observations |

## Tables

Use Markdown tables with captions where supported by the configured Pandoc filters. Keep source values traceable to a JSON/CSV artifact and state rounding in prose.

## Security

Never place API keys, response bodies, authorization headers, or private environment values in manuscript source or generated figures.
