What the local corpus actually does

FractiSkills walks monorepo registries, renders a SKILL.md package per surface under skills/<area>/<id>/, and writes skills/index.json. Regenerate with npm run generate:lattice-skills. The current local index locks around 421 packages — a structural count, not a prophecy that the public web was crawled into finished physics. Runtime returns at most eight pointers and pinches at most two skill bodies. That pinch is the product: enough orientation for a child agent, not a fat dump that melts the token margin.

Why portable skills beat paste culture

Paste culture looks fast until nested agents multiply. Each child re-inlines the same whitepaper. Costs climb. Coherence drops. Soft Story and measured rails blur. Portable skills reverse that: one thin brief per surface, pointer-first retrieval, shared index, regenerate when the monorepo moves. Guests still get hospitality — a human ship-blog note first — while builders get a regenerable corpus that stays inside honesty rails.
