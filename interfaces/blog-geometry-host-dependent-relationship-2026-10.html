Does the Same Rule Draw Different Shapes When the Terrain Changes?

FractiAI Research — October 15, 2026

A kid’s walk to school reroutes when construction fences go up; the goal stays the same while the path geometry changes. Rent, bus schedules, and paychecks still bind to the old straight-line fantasy on a map that no longer matches the sidewalk. This Homeostasis Expedition paper asks a disciplined version of that everyday fact for mathematics and biology: when we treat geometry as something systems manifest inside environments—not as shapes floating free of context—can we separate (a) how the host shapes what appears from (b) whether some relationship recurs across unlike hosts? The guiding phrase is poetic—we are equations, a fractal with a rhyme—but the executed work is narrow: a reproducible grid experiment plus a research framework whose heavier stages remain open.

Computational lab experiments and findings (plain)

Experiment GHDR-1 is intentionally small. On a two-dimensional grid, a traveler moves from a fixed start to a fixed end using eight-neighbor steps (including diagonals with √2 cost and blocked corner cuts). Both hosts optimize the same objective: minimize total path length. Host A is open ground; Host B inserts a vertical barrier segment that forces a detour. Euclidean straight-line distance stays 28.00 units in both cases. On Host A the optimal route is straight: length 28.00, ratio to straight line 1.000, and zero direction changes. On Host B the optimal route lengthens to about 34.63 units (replay ≈34.627), ratio about 1.237, with five direction changes—roughly a twenty-four percent penalty versus the unobstructed optimum, matching the manuscript table within fixture tolerance.

That is the entire executed empirical core for this ship note: host changed, rule did not, geometry did. The paper does not analyze forest canopies or ant colonies, does not estimate fractal dimensions on natural data, and does not demonstrate that a rhyme repeats across domains. Those are Stage B–C objectives with prespecified mappings and null models—exported in the suite as checklist experiment E8, not as pass/fail biology.

The problem: shapes without hosts

Fractal and network methods already warn against label inflation: complexity or a pretty branching photo does not by itself earn a fractal claim (Halley et al., 2004). Network geometry can reveal organization invisible in silhouette (Boguñá et al., 2021). Ecological networks shift with environmental gradients (Tylianakis & Morris, 2017). The expedition’s move is to make host dependence explicit in the explanation for manifested geometry while holding cross-host recurrence as a separate hypothesis that must beat null models—not win a metaphor contest.

Abstract mathematical spaces can exist without physical hosts; the proposition here concerns systems in environments where soil, terrain, pheromone fields, or grid barriers participate in producing the geometry you measure.

Hypothesis structure: H1 executed, H2–H4 open

H1 (host dependence) predicts that changing relevant host constraints changes measurable geometric properties while holding the governing rule fixed. GHDR-1 supports this in synthetic form: barrier host increases optimal route length with the same shortest-path objective. H2 (cross-host relational recurrence), H3 (host-conditioned recurrence), and H4 (added explanatory value over baselines) are defined with falsification criteria in the paper but are not executed in the current receipt—honest status, not a buried limitation.

The proposed modeling shell \(G=\Phi(R,H,C,D)\) (relationships, host, constraints, domain) is a filing tool. It becomes testable only when \(\Phi\) and maps \(M_1,M_2\) are specified before confirmatory looks—preventing post-hoc representation shopping.

Results with qualifications

The mixed headline matches the tier labels. Positive: a clean, replayable host effect under a declared optimizer; Infinite Octaves engine companion slot #48 on the Homeostasis Expedition trail. Literature synthesis is focused, not systematic; novelty remains provisional if adjacent frameworks already combine similar ingredients.

Framework value and invitation

For biologists and network scientists, the value is procedural: prespecify relationships, hosts, mappings, and nulls before claiming rhyme across trees and colonies. For engineers and routing systems, GHDR-1 is a toy reminder that identical objectives yield different manifested networks when feasible sets change—relevant to traffic, logistics, and agent pathfinding, with obvious scaling limits. For readers navigating real rent and real detours, the metaphor is host-shaped paths, not proof that your neighborhood is a fractal.
