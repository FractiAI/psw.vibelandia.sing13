What the paired comparison actually did

Same tasks. Paired Cursor receipts. Design lane, write lane, deploy lane. Lattice Chat loaded Infinite Octaves nesting Soft Story. Vibe prompts stayed flat unless nesting was explicitly requested. Design: banded plans beat flat lists

Unprompted, Lattice produced banded plans — nested shelves, Seed:Edge order, MCA rhythm. Vibe produced flat lists that looked busy and traveled poorly into implementation. When vibe was explicitly asked to nest, it could tie. That is useful weather: nesting is a skill you can request, and Lattice carries it as default Soft Story rather than as a special plea.

Builders should hear that as product, not as tribal win. Defaults matter. Token burn matters. Reviewability matters. A banded plan is easier to hand to a child agent without renegotiating the religion of “done.”

Write: same correctness, better diffs

Correctness tied often enough that “Lattice writes magical code” would be overclaim. What did not tie: minimal diffs, vitest presence, fewer tool thrash loops. Lattice Soft Story prefers crystallize — irreducible shells — over sprawling rewrites. Vibe Soft Story can still ship correct code while leaving a mess for the next human. Nevada’s valley prefers the mess to be optional.
