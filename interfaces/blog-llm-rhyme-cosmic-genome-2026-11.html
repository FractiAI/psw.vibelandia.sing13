When You Pack the Sky and the Genome as Language, Does the Folding Rhyme Still Show Up?

FractiAI Research — November 18, 2026

A trail map without a legend is just scenery. Language models are often fed scenery — flat paragraphs — when the useful object is the legend: which row plays which role. Earlier expeditions showed that packing proteins, documents, and economic series as a short local window, a messy dump, or a ranked relationship board changes whether a reader can name the held-out partner. This note owns that language-pack question as its own expedition, aims it at public sky catalogs and a human-genome demonstration panel, and puts the legend up front so nobody has to guess which NASA row plays the role of a contact residue.

Why split this out?

Cosmic Rhyme already asked whether relationship boards beat linear reading on NASA, JPL, OpenNGC, and WMAP files, and whether leftovers after selection look like candidate physics. Language packing was hitchhiking as a fifth arm. Hitchhikers get lost. So we moved the LLM / language-pack rhyme here: same packing grammar as the protein, knowledge, and macro rhymes, owned as its own falsifiable question, with a genome exploration arm added on purpose, and with an explicit map from each public file into that grammar.

Legend · one line

Protein sequence leads to an MSA board and a contact residue. A knowledge passage leads to a title board and a supporting title pair. A macro series leads to a lag board and a teleconnected series. A cosmic catalog or spectrum leads to an AWARE language pack and a partner id. A human exon or mitochondrial window leads to an AWARE language pack and a partner id. Same rhyme. Different public file.

Legend · cosmic data mapped to the rhyme

Exoplanet rows from the NASA Exoplanet Archive become language tasks where the LINEAR window is neighboring planets along right ascension written as feature lines, the AWARE board is a ranked list of measured feature couplings between planets, and the gold answer is the strongest non-local partner planet id (same host treated as trivial). Near-Earth encounter rows from JPL close-approach data use a time or distance local window for LINEAR, an encounter-feature coupling board for AWARE, and a partner encounter id as gold. OpenNGC deep-sky objects use RA neighbors for LINEAR, morphology and sky-feature couplings for AWARE, and a partner object id as gold. The WMAP temperature spectrum uses a local multipole strip for LINEAR, a lag-correlation board on the Cl series for AWARE, and a partner ell as gold. In every case the numbers are the same; only the packing changes.

Legend · human genome mapped to the rhyme

On the genome demonstration arm, exons from a public GTEx and MyGene panel — with UCSC CpG proximity features — become objects whose LINEAR window is genomic-order neighbors and whose AWARE board ranks measured exon-feature couplings across genes. Same-gene exons are treated as trivial so the long-range task must cross genes; gold is the partner exon id. Sliding windows on the human mitochondrial sequence from UCSC become objects whose LINEAR window is sequence-order neighbors and whose AWARE board ranks GC, CpG density, and entropy couplings; gold is the partner window id. That is exploration on public panels anyone can re-download — not a clinic, not a wet lab, and not a slogan that DNA “is” a language model.

What we tested

For each held-out object we built three prompts from the same numbers. LINEAR shows only ordered neighbors as text. FLAT dumps more of the same material without ranks. AWARE adds a leading candidate and a ranked board of measured couplings — not gold labels typed in by hand. A pack-compliant reader follows those instructions. A lexical-blind reader ignores the board and only matches overlapping words. No frontier API key is required for the default receipt; live model calls stay optional. Parents who have waited for a school report and analysts who have waited for a spreadsheet join know the difference between a labeled map and a pile of rows that “ought to be enough.”

What happened

Under pack-compliant reading, AWARE recovered the gold partner on all four cosmic layers and on both genome layers, while LINEAR stayed near zero and FLAT stayed near zero. Lexical-blind reading that ignored the board failed. In kitchen English: when the prompt carries a relationship map, the partner is findable; when it only carries a neighborhood list or a pile of rows, it is not. That is the same shape we saw when proteins and documents were packed this way.

On the sky side, forty-eight held-out tasks per layer on exoplanets, near-Earth encounters, deep-sky objects, and the microwave spectrum all showed the same shape. On the genome side, a hundred twenty-five exons yielded fourteen long-range cross-gene tasks, and two hundred seventy-five mitochondrial windows yielded sixty-four tasks — again AWARE full, LINEAR empty, FLAT nearly empty. AWARE packs were also shorter than flat dumps on estimated tokens, so the ranked board was not buying accuracy with bulk.

How this sits next to Cosmic Rhyme

If you came for novel physics candidates in microwave residuals, that story still lives on the Cosmic Rhyme note — two WMAP residual lags as candidates under protocol, not confirmed laws. This note leaves that physics headline there and answers a different paycheck question: when sky rows and genome panels are written as language the way models actually see text, does the folding rhyme still appear? On these fixtures, yes — as method, not as fireworks — and the legend is how you check which file plays which role.

Why a careful legend still earns a seat

Teachers, analysts, and parents stretched between rent and curiosity do not need another claim that a chatbot discovered the universe. They need a regenerable receipt that changes representation, holds materials still, names the map, and says what survived. One npm script rebuilds this one. No account. No wallet. The whitepaper keeps the full tables. Disagree with an audit label if you have a sharper one. The next useful fight is whether a live model, not only a pack-compliant reader, still prefers the board when someone else holds the same public files and the same legend.
