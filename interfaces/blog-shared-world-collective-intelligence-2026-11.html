Do Rhyming World Models Outperform Non-Rhyming Ones?

FractiAI Research — November 18, 2026

Earlier expeditions already answered the first half of the story. When agents share a world that rhymes — same organization, even when the words differ — teams finish jobs that flat reconstruction cannot, under the same budget, in ways you can rerun and try to break. That is not a slogan. It is measured discovery, measured reuse, measured collective recovery. This expedition is the head-to-head that comes next: do rhyming world models outperform non-rhyming ones — exact caches, prefix tricks, plain blackboards, and the open latent predictors we can actually run? Weight the traffic that matters. Most real multi-agent work is same pattern, different words — not identical bytes pasted again.

The problem that pays the rent

Parents coordinating a school pickup, analysts merging three spreadsheets before a deadline, and coding agents editing one repository all hit the same tax: duplicated context. Someone already knew piece A. Someone else already knew piece B. The team still fails because nothing held A and B in one place long enough to use them. Prior FractiSI labs hinted that sharing a world once, then keeping local deltas, might cut that tax. A hint is not a comparative science result. So we built a harness that can also lose.

What we built

First we inspected the shipped FractiSI Multi-Agent kit — Tiny Footprint, Tiny Gateway, platform store, deltas, selective reconstruction, Git worktrees, conflict heuristics — and wrote that inventory down before redesigning anything. Then we defined a world model operationally: a system that maintains, predicts, reconstructs, or represents state agents need. We separated shared symbolic worlds, latent predictive models, generative simulators, and hybrids, so Genie’s pixels are not silently treated as a blackboard.

We gave every architecture the same WORLD interface — observe, read, write, predict, simulate, share, fork, merge, materialize, reset — and tagged each operation as native, adapter-provided, or unavailable. Unavailable means the harness throws. It does not invent a feature for marketing. Conditions ran as independent agents, shared text, shared structured state, FractiSI, FractiSI with deltas, and FractiSI with selective reconstruction. Worlds covered complementary knowledge chains, changing state, specialized planning roles, adversarial noise, and a relational puzzle where X near Y, Y moves with Z, and Z controlled by W must become “X is controlled by W.”

Hypothesis

Primary: collectives do better over a coherent shared world than by rebuilding overlapping private worlds. Secondary: shared base plus local deltas plus selective reconstruction improves useful collective intelligence per compute, latency, memory, and communication — not merely compression. The score that matters is useful work per cost, not a smaller dump that still fails the job.

What the fixtures showed

On regenerable Node fixtures with five seeds, independent agents scored zero live success on collective knowledge, planning, and relational worlds. They often “knew” the pieces in separate heads. They could not finish the joint answer without a share channel. Shared text and shared structured state both reached high collective success. FractiSI-shaped arms matched the structured blackboard on those success scores. That is a real win for the shared-world family. It is not a unique FractiSI crown.

Scaling made the cost story clearer. As agent counts rose toward thirty-two, independent worlds and shared text logs piled up duplicated bytes. Structured shared state and FractiSI selective arms stayed near a duplication ratio of one while keeping collective success. Relational intelligence needed the shared map: only when the three relations lived together did the team infer the control chain. An adversarial world showed the other edge of the knife — a shared world that spreads a bad fact without correction can be worse than silence — so the harness scored recovery, not only speed.

We also reproduced the existing FractiSI Expedition 002 discovery receipt: relationship-guided search found one hundred of one hundred six-hop solutions under a fixed budget while the flat baseline found zero, with far fewer operations. That older result still stands. It does not by itself prove FractiSI beats every alternative world model on every metric.

Where FractiSI did not win

On task success alone, FractiSI matched a shared blackboard. When we redesigned the expedition to stress rhyming pattern recognition on real PDB and Movebank data, rhyme beat exact-text caches whenever organization matched but wording differed — while still losing to simple prefix reuse when the shared string was identical. Genie, Cosmos, V-JEPA, and Dreamer were marked not executable in this seed. We did not invent their scores. A generative simulator that paints a beautiful room can still be a poor place for agents to merge facts. A compact shared state can look dull and still coordinate a team. Those are different jobs. Teachers grading group projects already know the difference between a pretty poster and a shared outline everyone can edit.

What this is worth

The honest takeaway is sharper after the redesign. Shared worlds remain a coordination primitive. FractiSI rhyme does outperform non-rhyming exact caches on real non-identical observations — protein contact boards and GPS track utterances included — without claiming a win over every baseline. Prefix reuse still wins when the text is truly identical. That is how a fair expedition should behave: it lets FractiSI excel where its pattern recognition matters, and lose where a simpler trick is enough.
