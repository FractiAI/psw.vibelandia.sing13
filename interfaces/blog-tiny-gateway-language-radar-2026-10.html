Can a Tiny Gateway Reuse Templates Faster Than Ordinary Pipelines on Real Data?

FractiAI Research — October 30, 2026

People who rebuild the same spreadsheet every Monday already know the cost of forgetting reusable structure. A dispatcher watching collar tracks on a winter range, a parent parsing a school portal message, a researcher asking whether last week’s method still answers this week’s question—each is testing whether a pathway can be bound to new data without rebuilding the whole machine. Tiny Gateway is FractiAI’s name for one such pathway: a boundary, a recursive tree, a golden-ratio scale bridge, a honeycomb of routes, and a wave–node–frequency selector that picks a template, binds incoming data, and executes. The Leo Computational Lab asked whether that stack earns its keep on real public history, not on a storyboard of invented airplanes.

The problem with synthetic scoreboards pretending to be the world

Architecture decks love clean numbers. Six sensors, one hundred eighty tracks, eighty time steps, eighty-six thousand four hundred observations—those figures showed up in an assignment brief, but the matching civilian airspace scripts and logs were not sitting in this repository. Inventing the airspace anyway would have been easy and dishonest. Paychecks, rent, and grant renewals all punish teams that quote a speedup measured on a fantasy feed. Leo’s rule is older and stricter: prefer live or historical public data; use synthetic only when the real sources are missing and an explicit flag allows the fallback. So the fusion arm did not cosplay air-traffic control. It used Movebank GPS collars from Snowy Range moose and archived GFZ Kp geomagnetic indices—the same public window the Tiny Reality Generation Model already treats as historical truth.

Language followed the same priority. Instead of a toy phrasebook alone, the suite pulled real repository text from the prime-vault corpus and real expedition questions from the Hero Leo ledger, then added only small labeled fillers where a structured capability would otherwise be absent. That mix is imperfect. It is also closer to how a working lab actually reads: messy documents, real questions, and a few synthetic probes for gaps.

What we built and what stayed provisional

The stack under test is not a slogan pasted on ordinary rules. Boundary nodes declare domain and entry. Recursive trees hold nested context. A golden-spiral scale bridge maps depth with the familiar Φ nesting ratio used elsewhere in the Infinite Octaves catalog—an organizational bridge for filing scale, not a physics costume. Honeycomb lattices carry hex pathways. Wave–node–frequency activation scores templates and cues execution. Template binding separates reusable structure from incoming data. Ablation switches can disable spiral, honeycomb, wave, or tree so the suite can ask which pieces move runtime.

Beside Tiny Gateway sat two conventional language arms: a lightweight TF-IDF and rule pipeline, and a pure JavaScript micro-Transformer with two layers and a small hashed vocabulary. Neither is a commercial large language model. Keeping that size honest keeps curiosity doors open without selling a clinic-grade chatbot. For fusion, a nearest-neighbor association baseline ran beside the gateway arm on the same Movebank-derived observations.

Hypothesis

If Tiny Gateway is more than filing theater, three things should show on locked seeds. First, language templates should organize bounded tasks at least as well as the lightweight baseline on the shared real-text set. Second, fusion on real multi-target GPS plus Kp should not collapse relative to the conventional tracker on precision, recall, and F1. Third, separating construction, binding, and execution should yield warm reuse that is cheaper end-to-end than rebuilding ordinary closures—because that reuse claim is the architectural heart of the brief. Engine pinning to Infinite Octaves shelf candidate fifty-four was allowed only if those measured gates cleared on real source modes.

What the live receipts show

Under seed twenty twenty-six ten thirty, experiments E1 through E8 passed eight of eight as a protocol. Language source mode was historical real corpus plus capability fillers. On fifty-three evaluation rows, Tiny Gateway accuracy landed near zero point five eight five. The lightweight arm and the micro-Transformer both landed near zero point three seven seven on the primary seed; a validation seed nudged the micro-Transformer to about zero point four one five while Tiny Gateway held. Training the gateway templates took a few milliseconds; training the micro-Transformer took tens. Four architectural role probes—language pathway, execution layer around a stub language model, partial replacement of neural intent routing, and a second specialized agent template—all returned okay. That is a bounded win for organization on real text. It does not hire itself out as the model that writes cover letters for laid-off workers.

Fusion source mode was historical Movebank plus Kp: six observers, twenty-three tracks, eighty hourly steps, eleven thousand forty observations. Conventional F1 and Tiny Gateway F1 both measured about zero point two six one—delta zero. The gateway paid more runtime on the full window, roughly one hundred twenty-four milliseconds against about thirty for the conventional arm. Kids learning to sort recycling already understand that a careful labeled system can match a hasty pile without beating it on speed; fusion here rhymes with that everyday draw. Anomaly labels themselves are heuristics on speed and storm-time Kp, so the absolute F1 is modest and honestly so.

Template binding told the sharpest negative. Warm end-to-end reuse, which includes wave–node selection and honeycomb pathway work, sat near eleven microseconds median. A bare conventional rebuild sat near four-tenths of a microsecond. The reuse-versus-rebuild gate therefore failed. Selection alone can look fast; end-to-end compute is what rent-day engineering has to pay. The suite refused to crown an engine pin on that evidence.

Framework value without a forced victory

Homeostasis Expedition already carries Wave–Node mathematics, the Tiny Reality Generation Model, and a predictive catalog on the engine shelf, plus a gateway agent scoreboard as an application companion. Tiny Gateway language-and-fusion adds a Leo Computational Lab receipt that prefers public history, measures three conventional contrasts, and publishes a mixed board: language accuracy edge, fusion parity, template overhead. That mix is useful precisely because it is mixed. Teams under layoff pressure do not need another brochure that only reports wins. They need a place where a favorite architecture can lose a gate in public and still leave a runnable suite for the next attempt.
