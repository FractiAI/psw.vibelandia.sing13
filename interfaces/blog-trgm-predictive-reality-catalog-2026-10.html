After a Generator Passes Once, Does It Still Predict on Held-Out Biology?

FractiAI Research — October 25, 2026

A recipe that works in one kitchen does not prove it works in the next. Parents checking a school portal already know the difference between one green check and a report card that survives a new quarter. The Tiny Reality Generation Model cleared a primary stack test—three-symbol cycles, polygon spin, octave rhyme tree, folded DNA, genetic nodes mapped to wave, node, and fq. The next question is colder and more useful: if you reproduce that battery from a clean checkout, reserve held-out biological regions, and compare against matched baselines, does the grammar still predict, and can every generated miniature be stored so someone else can retrieve, compare, and recombine it?

The problem of a passing score that never leaves the room

Laboratories and product teams both learn the same expensive lesson. You tune a classifier on the examples you love, celebrate accuracy, then watch it stumble on the next batch of resumes, loan files, or gene loci. Rent and grant cycles punish that pattern. TRGM #50 earned its shelf pin with a coherent stack and a one-hundred-ninety-nine-feature catalog. What it had not yet done was prove independent predictive value on regions reserved from the training panel, or ship a catalog of realities that behave like addressable artifacts instead of one-off screenshots. Without those rails, “tiny reality” stays a mood board. With them, the expedition gets a falsifiable next gate.

What we actually ran

The #51 suite imports the #50 runner cold. It hashes the pinned genetic fixtures—provenance, chromosome sizes, gene and exon panels, mitochondrial FASTA, CpG islands, and the wave/node/fq catalog—then re-executes the twenty-four-test battery and locks the metrics that already shipped: seed twenty twenty-six ten twenty-five, held-out viability one hundred percent against null zero, catalog length one hundred ninety-nine. Separately, genes on chromosome twenty-one stay in the train panel while insulin, PDX1, POMC, NPY, and the DNMT pair, plus mitochondrial and composition features, sit in the held-out set. The predictive task recovers triad channel labels for held-out non-gene features using the feature-kind grammar, not memorized panel gene names. Matched baselines include shuffled labels, conventional length and chromosome heuristics, a sequence-proxy that leans on CpG and coding cues, a flat encode without the recursive octave tree, and a null spatial layout without the DNA theater.

Hypothesis under test

If the architecture is more than a story told on the same examples twice, clean reproduction should match locked hashes and metrics; held-out feature-kind grammar should beat shuffle on balanced accuracy; architecture contrasts should still favor the octave tree and folded DNA theater; correct wave/node/fq symbol lock should keep polygon-spin clock sync high while a shuffled symbol map collapses motif hit rate; and a versioned reality catalog should store recipes with parameters, multiscale trees, spatial descriptors, and validation scores so records can be retrieved, compared, and recombined. Biology claims about living chromosomes stay off this track unless independent wet evidence arrives later.

What the held-out run found

Under validation seed twenty twenty-six ten twenty-five one, the V1 through V8 battery passed eight of eight. Clean reproduce locked twenty-four of twenty-four from #50 with one hundred ninety-nine catalog entries and hashed fixtures. The held-out split reserved six non-chromosome-twenty-one genes and one hundred thirty-four related entries against a chromosome-twenty-one train panel. Feature-kind channel grammar reached balanced accuracy one point zero on held-out non-gene features; shuffle landed near zero point three four. Conventional heuristics scored about zero point eight zero. Sequence-proxy matched the grammar at one point zero when CpG and coding cues align with the same map—that tie is reported beside the win over shuffle, not sanded off. Architecture baselines kept the recursive tree coherent while flat encode was not; DNA theater viability stayed at one against null zero, with fold compaction near eighteen point eight versus unfolded one. Correct triad clock sync stayed at one hundred percent; a shuffled symbol permutation dropped motif hit rate to one third. Kids sorting laundry already know that labels on the wrong drawers make mornings late; the clock contrast is that same mismatch, measured.

A catalog you can open again tomorrow

Passing tests still leave a practical hole if every generated miniature evaporates when the process exits. The functional reality catalog writes versioned JSON records under schema trgm-reality-catalog-record version one. Each record carries a stable reality identifier, the recipe lattice and oscillators and wave and map, seed parameters, a multiscale tree summary, spatial counts, a pointer into the genetic catalog, and validation metrics for geometry, wave error, soft phase, and navigation. Compare returns shared version, joint viability, wave and path deltas, nest depth agreement, and spatial node delta. Recombine takes lattice and oscillators from one parent and wave plus map size from another, then re-evaluates. The first store run holds nine records including one recombined hybrid. Factory floors already version tooling setups for the next shift; this catalog does that for tiny realities.

What this is for on the expedition trail

Homeostasis Expedition needs generators that stay viable while nesting, and it needs evidence that the labeling grammar still works when the genes change. Paychecks and tuition bills both punish systems that only pass on the demo set. TRGM #51 is the independent predictive gate and the reusable store for those miniatures. It does not replace clinical genetics, wet chromatin assays, or hardware safety rails. It does give the expedition a reproducible way to ask whether wave, node, and fq assignments earn their keep against shuffle and conventional baselines, and whether a generated structure remains findable after the meeting ends.

Framework value without a victory lap

Beating shuffle on held-out feature kinds is a modest architectural win. Matching a sequence-proxy when both lean on the same CpG and coding cues is a useful qualification, not a crown. Architecture contrasts reconfirm recursion and DNA theater without inventing new physics. The reality catalog turns screenshots into addressable objects. Commuters stuck behind a stalled shuttle already understand software confidence that outruns clearance; the same caution applies here. A computational DNA-inspired representation is a legitimate research architecture. A claim about molecular mechanisms inside living chromosomes requires a separate biological evidence track that this paper does not open.
