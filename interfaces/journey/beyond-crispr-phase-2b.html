Lattice blind discovery lane

Phase 1 fixtures score candidates and shortlist unexplained gaps without crowning a winner. Phase 2b is the live try-on: paste a leak-free prompt into Lattice Chat (your key, your session), run anti-bias first, archive a receipt, and compare results to literature — rediscovery of already-characterized messenger hubs does not count as gap discovery.

Run it

  1. Export prompt from the suite: npm run export:phase-2b-beyond-crispr (monorepo or standalone).
  2. Open Lattice Chat with BYOK access.
  3. Paste data/phase_2b_lattice_prompt.txt as the first message — do not name CBASS, fixture IDs, or engine vocabulary as hints.
  4. Require 3–5 ranked candidates, each with a falsification test; declaredWinner stays null.
  5. Fill data/phase_2b_receipt.template.json from the session; store locally (no keys in git).

After the session

If the lead is genuinely unexplained, proceed to the C11 minimum wet-lab brief. If the session only rediscovers well-published cyclic nucleotide immune logic, classify as framework validation — not novelty.
