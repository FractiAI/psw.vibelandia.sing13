Rhyming vs non-rhyming world models

Real agent work is the same job in different words. A normal cache only helps when text is identical. A rhyming world model recognizes the pattern. We tested both on real data and on open-source models we ran ourselves.

Shared world vs private copies

5× to 20× more accurate

Open-source models, run for real

4 upstream models

DreamerV3, MuZero, TD-MPC2 and V-JEPA 2 ran on CPU. All are strong for one agent. None can share a world between agents. FractiSI does that.

With mostly identical text, an exact cache wins, and FractiSI keeps it. On the protein task a plain shared notebook also got every answer right, so there the gain is size, not accuracy. Two critical AI infrastructure challenges. One approach.

AI infrastructure is constrained by memory and time. Duplicated context, shared information reprinted per session, and intermediate representations burn accelerator memory and add preparation work—raising cost, contention, and latency.

Lower memoryReduce information that must remain independently resident. Pack more concurrent work per box.
Lower latencyCut unnecessary retrieval and reconstruction so the working set is ready sooner.
Better economicsStretch scarce accelerators further without surrendering your existing AI stack.
