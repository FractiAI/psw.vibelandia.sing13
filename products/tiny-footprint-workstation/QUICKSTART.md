# Quick start · FractiSI Multi-Agent

**Required:** Git + cloud token (`VERCEL_TOKEN` or `FRACTISI_CLOUD_TOKEN`).

1. Clone **https://github.com/FractiAI/FractiSI-Multi-Agent**
2. Open the folder in VS Code / Cursor
3. Run the end-to-end try path:

```bash
export VERCEL_TOKEN=…   # or FRACTISI_CLOUD_TOKEN
node scripts/tiny.mjs try
```

That creates worktrees, composes contributions, commits, and deploys a live preview URL.

4. Optional deeper kit path:

```bash
node scripts/tiny.mjs doctor
node scripts/tiny.mjs install
node scripts/tiny.mjs demo
node scripts/tiny.mjs benchmark
node scripts/tiny.mjs report
```

5. Join industry testing (optional share → **valetpru@gmail.com**):

```bash
node scripts/tiny.mjs join
```

6. Open `benchmarks/reports/customer-benchmark.html`

Tiny Footprint remains the Layer A execution core inside FractiSI Multi-Agent.

Read [README.md](./README.md) for product context and honesty rails.
