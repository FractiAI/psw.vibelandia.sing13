# Beyond CRISPR — Biological Discovery Challenge

Application companion Soft Story / catalog suite for SING 13.

**Question:** Does biology contain distributed systems that sense → encode → store → compare → respond → feedback — beyond cutter-centric CRISPR novelty?

**Method:** Anti-bias first · ten independent score axes · curated literature scan · ranked research queue (**no winner**) · ultimate architecture + novel falsifiable prediction.

**Not:** ENGINE_SHELF · wet-lab CRISPR replacement · Infinite Octave proof · manufactured novelty.

npm run research
