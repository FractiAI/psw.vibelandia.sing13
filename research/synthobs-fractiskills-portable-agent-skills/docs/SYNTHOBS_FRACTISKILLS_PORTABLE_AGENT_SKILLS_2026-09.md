## 2. What FractiSkills is (one skill per surface)

**FractiSkills** = portable agent skill packages in monorepo `skills/<area>/<id>/SKILL.md`, indexed by `skills/index.json`.

| Piece | Role |
|-------|------|
| **Frontmatter** | `id`, `name`, `description`, `tags`, `routes`, `sources` |
| **Body** | Short operational brief for that surface (honesty + how to navigate) |
| **Areas** | Core · Lattice · Papers · Protocols · Research · Interfaces · Ship-Blog · … |
| **Runtime** | `lib/lattice-skills.mjs` — match → pointer pack → optional pinch |

**One skill per surface** means: each registered paper, ship-blog note, protocol, research suite, or major interface can own a skill package so nested agents inherit a **pointer** instead of a fat dump. Skills **complement** whitepapers; they do not replace them.

## 4. Local corpus pipeline (`generate:lattice-skills`)

```text
registries (papers · ship-blog · protocols · research · interfaces)
        ↓  discover
   surface set
        ↓  render
  skills/<area>/<id>/SKILL.md
        ↓  index
     skills/index.json  (skillCount ≈ 421)
```

1. **Discover** — walk whitepaper registry, QUESTFEST blog posts, protocols, research suites, major interfaces.  
2. **Render** — write/update `SKILL.md` packages (curated Lattice/Core meta skills retained).  
3. **Index** — emit `skills/index.json` with honesty stamp and `skillCount`.
