# Frontier Agent Convergence Experiment

Blind independent frontier-agent investigation of a public SING13 artifact · FIRE-Bench situating · conformity contrast.

**Application companion (not ENGINE_SHELF).** Distinct from the Agentic Convergence (AHOIS landscape) suite. Agents receive the same minimal instruction and public URL, are not told what conclusion to find, keep outputs blind to one another, and are scored for structural convergence versus an agree-with-Pru control.

## Run

```bash
npm run research
# or from SING13 monorepo:
npm run research:synthobs-frontier-agent-convergence
```
