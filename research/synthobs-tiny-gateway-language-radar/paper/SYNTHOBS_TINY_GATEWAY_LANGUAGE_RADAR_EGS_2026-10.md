## Abstract

**Primary question.** Can FractiAI Tiny Gateway — Boundary Node → Recursive Tree → Golden Spiral scale bridge → Honeycomb Lattice → Wave–Node–Fq with explicit template binding — provide a reusable computational foundation for bounded language processing and high-rate multi-target fusion under Leo Computational Lab **real-data priority**?

**Methods.** Node ESM suite · seed `20261030` · language from prime-vault corpus + Hero Leo ledger · fusion from Movebank study 2548892515 GPS + GFZ Kp archive · conventional lightweight NLP · pure-JS micro-Transformer · conventional NN fusion · Tiny Gateway arms · ablations · template stage timing · E1–E8 gates · engine pin data-gated.

**Findings (executed).** **E1–E8 = 8/8.** Language: Tiny Gateway **0.585** accuracy vs lightweight **0.377** and micro-Transformer **0.377** (validation seed micro-TF **0.415**). Fusion: `historical_movebank_kp` · F1 **0.261** both pipelines (Δ **0**); Tiny Gateway runtime higher (~124 ms vs ~30 ms on full window). Template: warm end-to-end reuse **not** competitive with bare conventional rebuild (gate fails). Engine pin **not recommended**.

**Limitation.** Not ATC radar; not a frontier LLM; anomaly F1 on wildlife GPS+Kp heuristic is modest; template pathway overhead is measured cost, not a free lunch.

**Keywords:** Tiny Gateway; Leo Computational Lab; Movebank; GFZ Kp; template binding; Wave–Node–Fq; application companion.

## 1. Motivation

Reusable structure — construct once, bind many times — is a standing claim in FractiAI architecture talk. This program treats that claim as an experimental question across language and multi-target fusion, with **live/historical public data preferred** and synthetic fixtures only when sources are missing and explicitly allowed (`TINY_GATEWAY_ALLOW_SYNTHETIC=1`).

Prior ADS-B / civilian airspace scripts matching a 6×180×80×86 400 legend were **not found** in-repo. Per Leo Computational Lab policy, Experiment B uses **Movebank GPS + GFZ Kp** as the real historical multi-target substitute.

## 4. Experiment A — Small language model

**Arms:** conventional lightweight (TF-IDF + rules) · pure-JS micro-Transformer (2-layer stand-in) · Tiny Gateway language templates.

**Data:** `historical_real_corpus_plus_capability_fillers` · train 115 / test 49 / held-out 4.

**Results (primary seed):** Tiny Gateway accuracy **0.585**; lightweight **0.377**; micro-Transformer **0.377**. Train ms: lightweight **25.6**, micro-TF **37.0**, Tiny Gateway **2.6**. Roles (language architecture · LLM surround · partial neural replacement · multi-agent substrate) all **ok**.

**Interpretation:** On this bounded real-text battery, template+Wave–Node–Fq organization beats the two conventional arms on aggregate accuracy. Intent recognition remains weak across arms — not a general NLP victory.

---

## 5. Experiment B — Multisensor fusion (real historical)

**Primary fixture:** Movebank 2548892515 · window `2019-03-01T00` · 80 hourly steps · 23 individuals · 6 observers (4 geometric beacons + collar channel + Kp channel) · **11 040** observations · 3 anomaly tracks (speed/Kp heuristic).

**Results:** Conventional F1 **0.261** · Tiny Gateway F1 **0.261** · Δ **0**. Runtime: conventional **≈30 ms** · Tiny Gateway **≈124 ms**.

**Interpretation:** Architecture organizes fusion without accuracy loss vs conventional NN on this labeling; it does **not** win F1 and pays pathway/selection overhead. Not ATC radar.

---

## 6. Experiment C — Template binding

Stages timed independently. Warm end-to-end reuse median **≈0.011 ms** includes Wave–Node–Fq selection + honeycomb pathway. Bare conventional rebuild median **≈0.0004 ms**. **Reuse gate fails** — do not equate template selection with end-to-end advantage.
